# Music Streaming Analysis: Genre Trends by User Tier (2018–2023)

This project provides a longitudinal analysis of music consumption habits, segmented by user subscription status (Free vs. Paid) and musical genre. Using data visualization, the study identifies growth patterns and shifts in listener behavior over a six-year period.

## Project Overview
The core objective of this analysis is to evaluate how different user tiers engage with specific music genres. By tracking "Listens," the project offers insights into platform growth and the effectiveness of the paid subscription model in driving higher engagement.

## Key Features
*   **Multi-Dimensional Growth Tracking:** Analysis of five major genres—**Rock, Pop, Indie, Hip-Hop, and Electronic**.
*   **Subscription Segmenting:** Comparative data between **Free** and **Paid** user tiers, showing a consistent 2x–3x engagement lead for paid subscribers.
*   **Time-Series Visualization:** A stacked bar chart illustrating total listen volume growing from ~7,000 (2018 Free) to over 22,500 (2023 Paid).
*   **Trend Identification:** Highlights the steady dominance of **Rock** and **Pop** across all tiers, while tracking the relative stability of the **Electronic** genre.

## Tech Stack & Tools
*   **Google Sheets / Excel:** Utilized for data aggregation, user tier partitioning, and stacked bar chart generation.
*   **Data Modeling:** Implementation of time-series grouping to compare year-over-year performance between free and premium cohorts.

## Analysis Summary
The data demonstrates a clear "Engagement Gap" where **Paid users consistently outpace Free users** in total listen volume across every year recorded. By 2023, the Paid tier reached a peak of approximately **22,500 listens**, nearly doubling the engagement of the Free tier within the same year. This indicates that while the Free tier remains a steady entry point, the Paid tier is the primary driver of platform volume.
