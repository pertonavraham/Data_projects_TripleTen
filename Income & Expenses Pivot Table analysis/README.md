Business Operations Analysis: Service and Product Performance
Project Description
This project focuses on analyzing the operational efficiency and financial performance of a B2B service-based business. Using data from June and July 2021, the analysis evaluates income and expense patterns across various categories, including standard haircuts, senior styling, and retail product sales (e.g., scrunchies, towels, shampoo).
The project involves cleaning raw transactional data, performing currency conversions (USD to GBP/EUR), and summarizing key performance indicators (KPIs) through pivot tables and visual charts to identify growth opportunities and cost-saving measures.
Objectives
Data Transformation: Clean and structure raw transactional data by extracting date components and normalizing currency values.
Financial Analysis: Calculate subtotals and converted totals in GBP using a fixed exchange rate (0.89).
Operational Insights: Categorize transactions into 'Income' and 'Expenses' to determine net profitability.
Business Intelligence: Summarize customer counts and revenue by state to identify primary market drivers.
Data Description
The dataset is derived from "Database A," specifically tracking B2B customer interactions.
Type: Categorization of the entry (Service vs. Product).
Operation: Financial flow (Income vs. Expense).
Category: Specific item or service provided.
Purchase Price / Subtotal: Original transaction values in USD.
Total in GBP: Calculated value using the assumed conversion rate of 0.89.
Project Structure
Assumptions & Change Log: Documentation of data constraints (June/July 2021 only) and version history (v1.1 - Data Cleaning, v1.2 - Pivot Analysis).
Raw Data: The original, unprocessed transactional logs.
Processed Data: The refined dataset featuring extracted months, applied discounts, and currency conversions.
Key Insights
Service Dominance: "Haircut by Senior" and "Haircut and Styling" represent the highest-value income streams per transaction.
Operational Costs: Consistent expenses are driven by product maintenance and inventory, such as towels and shampoo.
B2B Focus: The data is filtered strictly for B2B customers, providing a niche view of corporate or wholesale service demand.
Tools Used
Excel/Google Sheets: For data processing, pivot tables, and currency calculations.
Data Cleaning: Extraction of temporal data into separate columns for monthly trend analysis.
