# Strategic Logistics & Return Rate Analysis

This repository contains a comprehensive data analysis of product return patterns across various categories, geographic regions, and customer segments. Using multi-dimensional data visualization, this project identifies systemic inefficiencies and provides a roadmap for implementing stricter return policies to protect net margins.

## Project Overview
The core objective of this analysis is to diagnose the primary drivers of high return rates. By cross-referencing sales volume with calculated return percentages, the study highlights critical "danger zones" in the supply chain, particularly within the Technology and Furniture categories.

## Key Features
*   **Product Performance Benchmarking:** Identification of sub-categories with disproportionately high return rates, led by **Machines (35%)** and **Fasteners (32%)**.
*   **Customer Behavior Profiling:** Deep-dive into the "Top 10" return-prone customers, identifying accounts like **RM-19750** and **HH-15010** that exhibit a **100% return rate**.
*   **Geographic Return Mapping:** Regional analysis identifying **Utah** (100% in certain months) and **California** (79.8%) as states with critical return issues.
*   **Seasonal Trend Analysis:** Longitudinal tracking that reveals peak return surges during the **Summer months** and immediately following the **Holiday season**.

## Tech Stack & Tools
*   **Tableau / Business Intelligence:** Utilized for creating interactive dashboards, including scatter plots of **Sales vs. Total Returns** and geographic heat maps.
*   **Predictive Diagnostics:** Implementation of seasonal modeling to differentiate between "End of School Year" returns (Furniture/Office Supplies) and "Post-Holiday" returns (Technology).

## Strategic Recommendations
The analysis suggests implementing stricter return timeframes for the West Coast and Mountain regions during peak seasonal windows. Specifically, the organization should audit 100% return-rate products—such as the **Zebra GK420t Printer** and **Cisco SPA 501G IP Phone**—to determine if these are due to systemic defects or fraudulent customer behavior.
