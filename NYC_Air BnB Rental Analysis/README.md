# Manhattan Real Estate Investment Analysis

This repository contains a comprehensive data analysis of the Manhattan rental market, specifically focusing on identifying high-value investment opportunities within the 1-bedroom apartment segment.

## Project Overview
The primary goal of this analysis is to determine which Manhattan neighborhoods are most worthwhile for real estate investment. By analyzing rental attractiveness (defined by review volume) and revenue potential, this project provides a data-driven roadmap for property acquisition.
* Avraham Perton nyc_airbnb_data_v2: https://docs.google.com/spreadsheets/d/1R6I-wysNlAmmUWrgq7KIKusjLB_wqGyl5IxLRB8WuDo/edit?usp=sharing

## Key Features
*   **Neighborhood Tiering:** Identification of the top 10 neighborhoods based on rental frequency and total reviews.
*   **Revenue Modeling:** Automated calculations that project annual revenue based on 30-day rental cycles.
*   **Cleaned Dataset:** A refined version of raw Airbnb scrape data, including organized property characteristics and color-formatted financial performance indicators.
*   **Data Visualization:** Pivot tables and charts illustrating the relationship between property size (bedrooms) and market demand across Manhattan.

## Tech Stack & Tools
*   **Excel:** Used for core data cleaning, pivot table generation, and financial modeling.
*   **Data Profiling:** Comprehensive dictionary mapping for fields such as host details, listing descriptions, and neighborhood overviews.

## Analysis Summary
The data indicates that the **Lower East Side**, **Hells Kitchen**, and **Harlem** represent the top three neighborhoods for investment based on total review volume. The analysis specifically highlights that 1-bedroom rentals are the overarching factor in determining consistent revenue across these high-traffic areas.
